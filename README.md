# CFC Treino (v2.0)

App de estudo offline para o Exame de Suficiência do CFC (prova em 13/12/2026): 293 questões oficiais (FGV/CFC 2024.1–2026.2) com explicações, 50 questões autorais, simulados, Foco no peso, guia e fórmulas rápidas.

App online (PWA): https://vavastack.github.io/cfc-treino/

## Arquivos
- `index.html` + `manifest.webmanifest` + `sw.js` + `icons/`: versão PWA (instalável, funciona offline).
- `CFC-Treino-offline.html`: arquivo único; abre com duplo clique (sem instalar).

## Créditos
Idealizado e organizado por Wanderson Martins (MW). Desenvolvimento, explicações, guia e questões autorais escritos com o Claude (Anthropic), sob direção do criador. Sem bibliotecas de terceiros, sem anúncios e sem rastreamento.

## Fontes
- Provas do Exame de Suficiência em Contabilidade (tipo 1), edições 2024.1 a 2026.2, elaboradas pela FGV e divulgadas pelo CFC; gabaritos definitivos do CFC.
- As provas pertencem ao CFC e à FGV; uso para estudo pessoal, sem fins comerciais. Não venda este material.
- Explicações, guia e questões autorais não são oficiais: confira com a apostila e a norma vigente.

## Instalar como PWA
Abra o endereço acima no Chrome (celular ou PC) e use "Instalar app" / "Adicionar à tela inicial".

## Atenção
O progresso fica no navegador de cada endereço. Ao trocar de arquivo/endereço, use Exportar/Importar backup (JSON) no app.
